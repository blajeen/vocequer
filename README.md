# vocequer 🐶

Site simples e engraçado: você escreve uma pergunta, e a pessoa tem que responder **Sim** ou **Não**.

- O botão **Não** foge toda vez que alguém tenta clicar (mouse ou toque).
- A cada fuga, o **Sim** fica maior e aparecem bichinhos na tela.
- Ao clicar em **Sim**: chuva de bichinhos e comemoração.
- Dá para compartilhar a pergunta por link: `?q=Sua pergunta aqui`.

É só um `index.html` (HTML + CSS + JavaScript puro), sem build. Publicado na Vercel.
